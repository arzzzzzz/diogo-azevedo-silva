Repositório usado para subir arquivos relacionado ao curso da DIO.
Na ferramenta Excel, montei um simulador de investimento emfundos imobiliários, com aporte mensal, prazo em anos e taxade rendimento mensal. As perguntas respondidas, na aba INVESTIMENTO MENSAL, na ferramenta são:
1. Quanto investir por mês? (Na linha 20)
2. Por quantos anos? (Linha 21)
3. Taxa de Rendimento mensal? (Linha 22)
4. Patrimônio acumulado? (Linha 23)
5. Dividendos Mensais? (Linha 24)

Também, na mesma ferramenta, mostra o investimento de aporte aplicado em certa quantidade de tempo com uma taxa de rendimento constante, na aba de CENÁRIOS, e um dos cenários é o investimento feito por 2 anos, na linha 30. Utilizando a função VF para os cálculos, que essa função mostra quanto irá acumular utilizando o valor investido, o tempo e a taxa constante.

Na mesma ferramenta, é utilizada a função PROCV para calcular 3 diferentes perfis de investimento e os auxiliar para definir em quais fundos imobiliários investir mais ou menos. Na aba de PERFIl é possível alterar entre Moderado, Agressivo e Conservador, utilizando o mesmo valor de investimento, mas distribuindo de forma diferente nos fundos imobiliários quando se altera o perfil sugerido. O PROCV é utilizado com o auxílio de uma tabela auxiliar, fazendo a busca vertical dos dados e inserindo na tabela onde se pode alterar entre os três perfis. Um gráfico é disposto para facilitar a visualização, esse que também muda no momento que seleciona o perfil de investimento.
